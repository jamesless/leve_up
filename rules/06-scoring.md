# 六、抠底与底牌分计算

## 6.1 抠底定义

- **抠底**：最后一圈牌，抓分方（非庄家方）的牌最大
- 抠底成功后，底牌中的分数计入抓分方总分

## 6.2 抠底倍数

| 抠底牌型 | 倍数计算公式 | 实际倍数 | 说明 |
|----------|------------|---------|------|
| 单张抠底 | 2^(1-1) = 2^0 | ×1 | 用单张牌抠底 |
| 对子抠底 | 2^(2-1) = 2^1 | ×2 | 用对子抠底 |
| 三张抠底 | 2^(3-1) = 2^2 | ×4 | 用三张抠底 |
| 拖拉机抠底（4张） | 2^(4-1) = 2^3 | ×8 | 连对（2个对子）抠底 |
| 拖拉机抠底（6张） | 2^(6-1) = 2^5 | ×32 | 连对（3个对子）或连三（2个三张）抠底 |
| 拖拉机抠底（n张） | 2^(n-1) | — | n为拖拉机总牌数 |

**计算规则**：
- **公式**：倍数 = 2^(n-1)，其中 n 为牌型的张数
- **优先选择最大牌型**：如果出牌包含多种牌型（如对子+单张），按最大牌型计算
- **牌型优先级**：三张 > 对子 > 单张
- **甩牌规则**：如果甩牌都是散牌（单张），只算1倍；如果有对子，按对子算2倍

## 6.3 抠底示例

**示例1：对子抠底**
```
底牌分数：40 分
抠底牌型：对子抠底（2张）
倍数计算：2^(2-1) = 2
实际得分：40 × 2 = 80 分
```

**示例2：拖拉机抠底（4张）**
```
底牌分数：40 分
抠底牌型：连对（2个对子，4张）
倍数计算：2^(4-1) = 8
实际得分：40 × 8 = 320 分
```

**示例3：拖拉机抠底（6张）**
```
底牌分数：40 分
抠底牌型：连对（3个对子，6张）
倍数计算：2^(6-1) = 32
实际得分：40 × 32 = 1280 分
```

## 测试场景

### 场景 6.1：抠底定义验证
- **前置条件**：最后一圈牌
- **测试步骤**：抓分方出最大牌
- **预期结果**：抓分方赢得最后一圈，底牌分计入抓分方总分

### 场景 6.2：非抠底情况
- **前置条件**：最后一圈牌
- **测试步骤**：庄家方出最大牌
- **预期结果**：庄家方赢得最后一圈，底牌分不计入抓分方

### 场景 6.3：单张抠底倍数
- **前置条件**：抓分方用单张牌抠底成功
- **测试步骤**：计算底牌分倍数
- **预期结果**：底牌分 × 1

### 场景 6.4：对子抠底倍数
- **前置条件**：抓分方用对子抠底成功，底牌40分
- **测试步骤**：计算底牌分倍数
- **预期结果**：40 × 2 = 80 分

### 场景 6.5：三张抠底倍数
- **前置条件**：抓分方用三张抠底成功，底牌40分
- **测试步骤**：计算底牌分倍数
- **预期结果**：40 × 4 = 160 分

### 场景 6.6：拖拉机抠底（4张）倍数
- **前置条件**：抓分方用4张拖拉机（连对）抠底成功，底牌40分
- **测试步骤**：计算底牌分倍数
- **预期结果**：40 × 8 = 320 分

### 场景 6.7：拖拉机抠底（6张）倍数
- **前置条件**：抓分方用6张拖拉机抠底成功，底牌40分
- **测试步骤**：计算底牌分倍数
- **预期结果**：40 × 32 = 1280 分

### 场景 6.8：底牌无分数抠底
- **前置条件**：底牌没有分值牌，抓分方用对子抠底
- **测试步骤**：计算得分
- **预期结果**：0 × 2 = 0 分

### 场景 6.9：混合牌型抠底-按最大牌型
- **前置条件**：抓分方出牌包含对子+单张
- **测试步骤**：计算抠底倍数
- **预期结果**：按对子计算，倍数为2

### 场景 6.10：甩牌抠底-全散牌
- **前置条件**：抓分方甩牌全是散牌抠底成功
- **测试步骤**：计算抠底倍数
- **预期结果**：倍数为1

### 场景 6.11：甩牌抠底-含对子
- **前置条件**：抓分方甩牌含对子抠底成功
- **测试步骤**：计算抠底倍数
- **预期结果**：按对子计算，倍数为2

### 场景 6.12：边界值-最大底牌分
- **前置条件**：底牌含3张K（30分），用6张拖拉机抠底
- **测试步骤**：计算得分
- **预期结果**：30 × 32 = 960 分

### 场景 6.13：公式验证 2^(n-1)
- **前置条件**：不同张数的牌型抠底
- **测试步骤**：验证 n=1,2,3,4,5,6 的倍数
- **预期结果**：
  - n=1: 2^0 = 1
  - n=2: 2^1 = 2
  - n=3: 2^2 = 4
  - n=4: 2^3 = 8
  - n=5: 2^4 = 16
  - n=6: 2^5 = 32
