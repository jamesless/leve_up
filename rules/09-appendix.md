# 附录：游戏流程图

```
┌─────────────────────────────────────────────────────────┐
│                        游戏开始                          │
└─────────────────────────────────────────────────────────┘
                            ↓
┌─────────────────────────────────────────────────────────┐
│  发牌（每人31张）+ 留底牌（7张）                          │
│  ★ 发牌期间即可亮庄/反庄（发牌期间不倒计时）              │
└─────────────────────────────────────────────────────────┘
                            ↓
┌─────────────────────────────────────────────────────────┐
│  亮庄 → 反庄 → 确定庄家和主花色                            │
│  （初始 10 秒倒计时在"最后一张牌发完"瞬间启动；            │
│    亮庄/反庄后追加 5 秒；所有未亮庄玩家都按"不叫庄"则      │
│    立刻结束；倒计时归零仍无人亮庄则进入翻底牌兜底流程）    │
└─────────────────────────────────────────────────────────┘
                            ↓
┌─────────────────────────────────────────────────────────┐
│  庄家流程：                                              │
│  1. 拿底牌（7张）                                        │
│  2. 叫朋友（指定一张牌）                                  │
│  3. 扣回底牌（7张）                                      │
└─────────────────────────────────────────────────────────┘
                            ↓
┌─────────────────────────────────────────────────────────┐
│  开始出牌（直到手牌出完）：                                │
│  - 每轮最大者获得分数和下一轮出牌权                         │
│  - 当朋友牌被打出时，识别盟友身份                          │
│  - 轮数根据出牌方式而定（单张/对子/三张/拖拉机等）          │
└─────────────────────────────────────────────────────────┘
                            ↓
┌─────────────────────────────────────────────────────────┐
│  最后一圈：判断是否抠底                                    │
└─────────────────────────────────────────────────────────┘
                            ↓
┌─────────────────────────────────────────────────────────┐
│  结算分数 → 升级 → 下一局                                  │
└─────────────────────────────────────────────────────────┘
```

## 测试场景

### 场景 A.1：完整游戏流程
- **前置条件**：5名玩家准备就绪
- **测试步骤**：完成一局完整游戏
- **预期结果**：按流程图顺序执行所有阶段

### 场景 A.2：发牌阶段流程
- **前置条件**：游戏开始
- **测试步骤**：执行发牌
- **预期结果**：每人31张，底牌7张

### 场景 A.3：亮庄阶段流程
- **前置条件**：发牌开始（无需等到发完，但倒计时只在发完后才走）
- **测试步骤**：执行亮庄/反庄流程
- **预期结果**：确定庄家和主花色

### 场景 A.4：庄家流程阶段
- **前置条件**：庄家确定
- **测试步骤**：执行庄家流程
- **预期结果**：完成拿底牌、叫朋友、扣底牌

### 场景 A.5：出牌阶段流程
- **前置条件**：庄家流程完成
- **测试步骤**：执行出牌流程
- **预期结果**：所有玩家手牌出完

### 场景 A.6：抠底判断流程
- **前置条件**：最后一圈出牌
- **测试步骤**：判断抠底
- **预期结果**：正确判断是否抠底及倍数

### 场景 A.7：结算流程
- **前置条件**：出牌完成
- **测试步骤**：执行结算
- **预期结果**：计算分数、升级、判断胜负

### 场景 A.8：下一局流程
- **前置条件**：结算完成，无人获胜
- **测试步骤**：开始下一局
- **预期结果**：按规则确定发牌者，重新开始

### 场景 A.9：游戏结束流程
- **前置条件**：有玩家A级获胜
- **测试步骤**：检查游戏状态
- **预期结果**：游戏结束，显示冠军

### 场景 A.10：流程中断恢复
- **前置条件**：游戏进行中断线
- **测试步骤**：玩家重连
- **预期结果**：恢复到中断时的游戏状态
