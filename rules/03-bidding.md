# 三、亮庄、反庄规则

> **术语统一**：本规则中**只使用"亮庄"与"反庄"两个术语**，不再使用"抢庄"一词（含义模糊，已废弃）。
> - **亮庄**：玩家主动亮出级牌确立自己为临时庄家。
> - **反庄**：在已有临时庄家的情况下，其他玩家亮出更多张级牌覆盖之前的亮庄。

## 3.0 时序定义（核心）

亮庄/反庄遵循以下严格时序：

```
┌──────────────────────────────────────────────────────────────────┐
│  阶段一：发牌期间                                                 │
│  - 玩家拿到第一张牌起即可亮庄/反庄                                │
│  - 发牌期间 **不启动** 任何倒计时                                  │
│  - 即使有人已亮庄，发牌仍按节奏继续把剩余的牌发完                  │
└──────────────────────────────────────────────────────────────────┘
                            ↓ 最后一张牌发完
┌──────────────────────────────────────────────────────────────────┐
│  阶段二：初始倒计时（10 秒）                                       │
│  - 发完最后一张牌的瞬间启动 10 秒倒计时                            │
│  - 期间任何玩家可亮庄/反庄                                         │
│  - 一旦有人在 10 秒内做出亮庄或反庄操作，倒计时追加 5 秒           │
│  - 一旦所有未亮庄的玩家都按了 "不叫庄"，倒计时立刻结束              │
└──────────────────────────────────────────────────────────────────┘
                            ↓ 倒计时归零
┌──────────────────────────────────────────────────────────────────┐
│  阶段三：定庄                                                     │
│  - 倒计时内有人亮庄：最后一次亮庄/反庄者成为庄家                   │
│  - 倒计时内全程无人亮庄：进入"翻底牌阶段"                          │
└──────────────────────────────────────────────────────────────────┘
                            ↓ 无人亮庄
┌──────────────────────────────────────────────────────────────────┐
│  阶段四：翻底牌（兜底定庄）                                        │
│  - 把 7 张底牌从左到右依次翻开，每 3 秒翻一张                      │
│  - 翻到的牌点数等于场上某玩家等级时立刻停止，由该玩家当庄          │
│  - 7 张全翻完仍无匹配：由首发人当庄（详见 3.5）                    │
└──────────────────────────────────────────────────────────────────┘
```

## 3.1 倒计时规则

| 字段 | 取值 | 触发时机 |
|------|------|---------|
| **初始倒计时** | 10 秒 | **发完最后一张牌的瞬间**启动（发牌阶段不倒计时） |
| **追加倒计时** | 5 秒 | 在倒计时内发生亮庄/反庄操作后追加（覆盖剩余时长） |
| **提前结束** | 立刻 0 秒 | 所有"未亮庄玩家"都按了 "不叫庄" 按钮 |

- 倒计时只在"发完牌之后"运行，发牌期间无倒计时（虽允许亮庄/反庄）。
- "不叫庄"按钮在发牌阶段也可点；点了之后该玩家本轮不再有亮庄机会。

## 3.2 亮庄规则

- 玩家使用**级牌**亮庄。
- 用哪门花色的级牌亮庄，哪门就是主牌花色。
- **示例**：当前打 2，用红桃 2 亮庄，则红桃为主牌花色。

### 亮庄类型

| 亮庄类型 | 说明 | 主牌花色 |
|----------|------|----------|
| 单张亮庄 | 亮出一张级牌 | 该级牌的花色 |
| 对子亮庄 | 亮出一对级牌 | 该级牌的花色 |
| 三张亮庄 | 亮出三张级牌 | 该级牌的花色，且封顶无法被反 |

## 3.3 反庄规则

### 反庄基础规则

**核心规则**：反庄者所亮张数只需 **多于** 临时庄家所亮张数即可（不要求恰好多一张，受 3 张封顶限制）。

- 单张亮庄 → 至少用两张反庄（两张或三张均可）
- 两张亮庄 → 至少用三张反庄
- 三张亮庄 → 已封顶，不能再反

### 反庄方式

**方式一：用临时庄家的级牌反庄**

- 使用**临时庄家的级牌**反庄
- 反庄成功后，**庄家不变**，只变**主牌花色**
- **示例**：
  ```
  玩家A用一张红桃2亮庄 → 玩家A成为临时庄家，主牌为2，主牌花色为红桃
  玩家B用两张方片2反庄 → 庄家依旧为玩家A，主牌为2，主牌花色变为方片
  ```

**特殊情况：反庄者的级牌也是2**
- 当临时庄家打2，反庄者的级牌也是2时
- 使用2反庄时，**庄家会转移**给反庄者，同时改变主牌花色
- **示例**：
  ```
  玩家A用一张红桃2亮庄 → 玩家A成为临时庄家，主牌为2，主牌花色为红桃
  玩家B的级牌也是2，用两张方片2反庄 → 临时庄家变为玩家B，主牌为2，主牌花色变为方片
  ```

**方式二：用玩家自己的级牌反庄**

- 使用**玩家自己的级牌**反庄
- 反庄成功后，**玩家变为临时庄家**，主牌花色变为玩家亮的花色
- **示例**：
  ```
  玩家A用一张红桃2亮庄 → 玩家A成为临时庄家，主牌为2，主牌花色为红桃
  玩家B的级牌为3，用两张黑桃3反庄 → 临时庄家变为玩家B，主牌为3，主牌花色变为黑桃
  ```

### 反主强度

三副牌专用规则，最多反到 3 张：

| 强度 | 反庄牌型 | 可反对象 | 说明 |
|------|----------|----------|------|
| 1 | 单张级牌 | — | — |
| 2 | 两张相同级牌 | 单张 | 可反单张级牌 |
| 3 | 三张相同级牌 | 单张、两张 | 可反单张级牌和两张级牌，封顶不能再反 |

### 反庄流程图

```
亮庄 → 玩家A反庄 → 玩家B再反 → ... → 确定最终庄家和主花色
 ↓      ↓            ↓
单张2   对子2        三张2        (反主强度递增)
```

## 3.4 翻底牌定庄规则

**触发条件**（同时满足）：
1. 发牌已完成（最后一张牌已派出）
2. 阶段二的初始倒计时已结束（或所有人按了"不叫庄"导致提前结束）
3. 全程没有任何玩家亮庄

**翻牌动画与节奏**：
- 7 张底牌在牌垫上从左到右排开，初始全部背面朝上
- **每 3 秒翻开一张**，从左到右（即 BottomCards[0] → [6]）
- 翻到的牌点数 = 场上某玩家等级时立刻停止后续翻牌
- 如多个玩家等级相同，按逆时针顺序，距离起始发牌人最近的玩家当庄
- 翻出的牌的花色作为主牌花色，该牌作为本轮主牌（比大小王小，比其他主牌大）

**示例**：

```
当前打2级：
玩家A：2级
玩家B：3级
玩家C：2级
玩家D：4级
玩家E：5级
起始发牌人：玩家A
翻出第一张底牌：方片2

结果：
- 玩家A和玩家C都是2级
- 按逆时针顺序，玩家A距离首发人（自己）最近
- 玩家A成为庄家
- 方片2成为本轮主牌
```

## 3.5 首发人当庄规则

当 7 张底牌全翻完仍未定庄时：

| 项目 | 规则 |
|------|------|
| **庄家** | 起始发牌人 |
| **主牌花色** | 从第七张开始往前找，第一张有花色的底牌的花色 |
| **主牌等级** | 首发人的等级 |

**确定主牌花色的规则**：
- 从第七张底牌开始检查
- 如果是有花色的牌（♠♥♣♦），该花色作为主花色
- 如果是王（大王/小王），往前找第六张
- 如果第六张也是王，继续往前找第五张
- 依此类推，直到找到有花色的牌

**示例1：第七张有花色**
```
首发人等级：4级
第七张底牌：方片8

结果：
- 首发人成为庄家
- 方片作为主牌花色
- 本轮游戏打方片4
```

**示例2：第七张是王**
```
首发人等级：4级
第七张底牌：大王
第六张底牌：红桃10

结果：
- 首发人成为庄家
- 红桃作为主牌花色（第六张）
- 本轮游戏打红桃4
```

**示例3：连续多张是王**
```
首发人等级：4级
第七张底牌：大王
第六张底牌：小王
第五张底牌：黑桃5

结果：
- 首发人成为庄家
- 黑桃作为主牌花色（第五张）
- 本轮游戏打黑桃4
```

## 3.6 级牌定义

- **级牌**：玩家当前的等级牌
- 例如：打2级时，所有花色的2都是级牌
- 打3级时，所有花色的3都是级牌

## 3.7 定主

- 按亮庄/反庄最终结果确定主花色
- 确定后全场公告主牌花色

## 测试场景

### 场景 3.1：发牌中可亮庄
- **前置条件**：游戏开始，正在发牌
- **测试步骤**：玩家拿到第一张级牌后立即亮庄
- **预期结果**：玩家成为临时庄家，发牌继续；不显示倒计时

### 场景 3.2：单张级牌亮庄
- **前置条件**：发牌或初始倒计时阶段，玩家手中有级牌
- **测试步骤**：玩家亮出一张红桃2
- **预期结果**：该玩家成为临时庄家，红桃为临时主牌花色

### 场景 3.3：对子级牌亮庄
- **前置条件**：发牌或初始倒计时阶段，玩家手中有对子级牌
- **测试步骤**：玩家亮出两张方片2
- **预期结果**：该玩家成为临时庄家，方片为临时主牌花色

### 场景 3.4：三张级牌亮庄
- **前置条件**：发牌或初始倒计时阶段，玩家手中有三张级牌
- **测试步骤**：玩家亮出三张黑桃2
- **预期结果**：该玩家成为临时庄家，黑桃为临时主牌花色，封顶不能再反

### 场景 3.5：发牌完成后启动初始倒计时
- **前置条件**：最后一张牌刚刚发出
- **测试步骤**：观察 UI
- **预期结果**：立刻出现 10 秒倒计时

### 场景 3.6：亮庄后追加倒计时
- **前置条件**：初始倒计时进行中，有玩家亮庄或反庄
- **测试步骤**：观察倒计时变化
- **预期结果**：倒计时刷新为 5 秒

### 场景 3.7：用临时庄家级牌反庄（临时庄家打2，反庄者打3）
- **前置条件**：玩家A用一张红桃2亮庄，玩家B打3级
- **测试步骤**：玩家B用两张方片2反庄
- **预期结果**：庄家依旧是玩家A，主牌花色变为方片

### 场景 3.8：用临时庄家级牌反庄（两者级牌相同）
- **前置条件**：玩家A用一张红桃2亮庄，玩家B也打2级
- **测试步骤**：玩家B用两张方片2反庄
- **预期结果**：庄家变为玩家B，主牌花色变为方片

### 场景 3.9：用自己级牌反庄
- **前置条件**：玩家A用一张红桃2亮庄，玩家B打3级
- **测试步骤**：玩家B用两张黑桃3反庄
- **预期结果**：临时庄家变为玩家B，主牌为3，主牌花色变为黑桃

### 场景 3.10：三张亮庄后不能反
- **前置条件**：玩家A用三张红桃2亮庄
- **测试步骤**：其他玩家尝试反庄
- **预期结果**：无法反庄，玩家A确定为庄家

### 场景 3.11：所有人按"不叫庄"提前结束倒计时
- **前置条件**：初始倒计时进行中，无人亮庄
- **测试步骤**：所有玩家依次按"不叫庄"按钮
- **预期结果**：最后一人按下后倒计时立刻归零，进入翻底牌阶段

### 场景 3.12：无人亮庄，翻底牌定庄
- **前置条件**：10 秒初始倒计时结束，全程无人亮庄
- **测试步骤**：观察牌垫
- **预期结果**：7 张底牌从左到右每 3 秒翻一张

### 场景 3.13：翻牌定庄-单人匹配
- **前置条件**：无人亮庄，进入翻底牌阶段
- **测试步骤**：翻出方片5，场上只有玩家C打5级
- **预期结果**：玩家C成为庄家，方片为主牌花色，翻牌停止

### 场景 3.14：翻牌定庄-多人匹配
- **前置条件**：无人亮庄，起始发牌人为玩家A
- **测试步骤**：翻出方片2，玩家A和玩家C都打2级
- **预期结果**：按逆时针距离起始发牌人最近的玩家当庄

### 场景 3.15：翻完7张底牌仍未定庄-第七张有花色
- **前置条件**：7张底牌都不匹配任何玩家等级，第七张是方片8
- **测试步骤**：翻完7张底牌
- **预期结果**：起始发牌人成为庄家，方片为主牌花色

### 场景 3.16：翻完7张底牌仍未定庄-第七张是王
- **前置条件**：7张底牌都不匹配，第七张是大王，第六张是红桃10
- **测试步骤**：翻完7张底牌
- **预期结果**：起始发牌人成为庄家，红桃为主牌花色

### 场景 3.17：翻完7张底牌仍未定庄-连续多张是王
- **前置条件**：7张底牌都不匹配，第七张大王，第六张小王，第五张黑桃5
- **测试步骤**：翻完7张底牌
- **预期结果**：起始发牌人成为庄家，黑桃为主牌花色
