# 二、发牌规则

## 2.1 发牌基本规则

| 项目 | 说明 |
|------|------|
| **发牌方向** | 逆时针方向 |
| **每人发牌** | 31 张 |
| **底牌数量** | 7 张（全部发完后剩余的牌作为底牌） |

> **亮庄/反庄时机**：亮庄/反庄从发牌开始就可以进行，无需等到发完所有牌；但**倒计时只在发完最后一张牌之后才启动**。详见 [03-bidding.md](03-bidding.md#30-时序定义核心)。

## 2.2 起始发牌者规则

### 首局发牌

- **随机确定**：第一局刚开始时，随机指定一个玩家作为起始发牌者

### 后续局发牌

起始发牌者根据上一局结果确定：

| 上一局结果 | 起始发牌者 |
|------------|------------|
| **庄家赢（1V4）<br>庄家升级** | 庄家 |
| **庄家赢（2V3）<br>庄家升级** | 庄家的朋友 |
| **庄家输** | 逆时针最靠近庄家的玩家 |

## 2.3 发牌示例

**场景一：首局**
- 随机指定玩家1为起始发牌者
- 逆时针发牌：1 → 5 → 4 → 3 → 2 → 1 → ...

**场景二：庄家赢（1V4），庄家升级**
- 庄家为起始发牌者
- 逆时针发牌：庄家 → 5号位 → 4号位 → 3号位 → 2号位 → 庄家 → ...

**场景三：庄家赢（2V3），庄家升级**
- 庄家的朋友为起始发牌者
- 逆时针从朋友开始发牌

**场景四：庄家输**
- 逆时针最靠近庄家的玩家为起始发牌者
- 例如：庄家在1号位，则5号位（逆时针相邻）开始发牌

## 测试场景

### 场景 2.1：验证发牌方向
- **前置条件**：5名玩家按位置1-5就座
- **测试步骤**：观察发牌顺序
- **预期结果**：从起始发牌者开始，按 逆时针（1→5→4→3→2→1...）发牌

### 场景 2.2：验证每人发牌数量
- **前置条件**：开始新游戏
- **测试步骤**：发牌完成后检查每人手牌数量
- **预期结果**：每人31张

### 场景 2.3：验证底牌数量
- **前置条件**：开始新游戏
- **测试步骤**：发牌完成后检查底牌数量
- **预期结果**：7张

### 场景 2.4：首局随机发牌者
- **前置条件**：游戏首局
- **测试步骤**：开始游戏并检查起始发牌者
- **预期结果**：随机选择一名玩家作为起始发牌者

### 场景 2.5：庄家赢（1V4）后的发牌者
- **前置条件**：上一局庄家独打（1V4）且庄家升级
- **测试步骤**：检查新一局的起始发牌者
- **预期结果**：庄家为起始发牌者

### 场景 2.6：庄家赢（2V3）后的发牌者
- **前置条件**：上一局庄家有朋友（2V3）且庄家升级
- **测试步骤**：检查新一局的起始发牌者
- **预期结果**：庄家的朋友为起始发牌者

### 场景 2.7：庄家输后的发牌者
- **前置条件**：上一局庄家输了
- **测试步骤**：检查新一局的起始发牌者
- **预期结果**：逆时针最靠近庄家的玩家为起始发牌者

### 场景 2.8：庄家在1号位输后
- **前置条件**：上一局庄家在1号位且输了
- **测试步骤**：检查新一局的起始发牌者
- **预期结果**：5号位为起始发牌者
